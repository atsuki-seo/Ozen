レシピをコードで書きます。そのコードをもとに、作る前にまちがいを見つけ、誰がいつ何をするかまで決められます。

仕組み

同じレシピでも、台所や人数が変われば段取りも変わります。

料理のコードを書く

レシピを書く

手順は |> でつなぎます。量は 1 人分で書けます。

ご飯と野菜炒め（2 人分）yasaiItame.ozen 
recipe yasaiItame(servings: 2) {
  ingredients {
    rice: 75 g per serving
    onion: 1 pcs
    carrot: 1 pcs
  }
  let gohan = rice |> wash |> soak |> cookRice
  let onionCut = onion |> peel |> cut(style: slice)
  let carrotCut = carrot |> cut(style: julienne)
  let itame = fry([onionCut, carrotCut], 5 min)
  serve main {
    plate perPerson on Bowl { gohan }
    plate shared on FlatPlate { itame }
  }
}
kitchen duo : Options {
  cooks: 2
  serveAt: 60 min
}

食材や動作を足す

標準にない食材や動作は自分で定義できます。足したものにも同じ検査が効きます。

マンゴーラッシーmango.ozen 
axis ripeness : ordered { green, ripe }
ingredient Mango : Fruit {
  axes: ripeness, shape
}
action ripen(x: T, time: Time)
  -> T<ripeness: ripe> @unattended
action scoop(x: T<ripeness >= ripe>)
  -> T<shape: cut(biteSize)> {

recipe mangoLassi {
  ingredients { mango: Mango 1 pcs }
  let scooped = mango |> scoop

料理のコードを段取りにする

人数と出す時刻に合わせる

作る人数と出す時刻から、誰がいつ何をするかを決めます。下は「レシピを書く」のご飯と野菜炒めの段取りです。

手を使う作業 待つだけの作業 目盛り: 10 分

出す時刻を決めると、炒め物は出す直前に作ります。

作ったらすぐ使う

かき揚げの衣のように時間がたつと悪くなるものには @useWithin を付けます。衣は混ぜてから 5 分以内に使えるよう、玉ねぎを切った後に混ぜます。

玉ねぎとにんじんのかき揚げkakiage.ozen（抜粋） 
recipe kakiage {
  ingredients {
    egg: 1 pcs
    water: 200 ml
    onion: 1 pcs
    carrot: 1 pcs
  }
  let batter = whisk([egg, water]) @useWithin(5 min)
  let onionCut = onion |> peel |> cut(style: slice)
  let carrotCut = carrot |> cut(style: julienne)
  let coated = coat([onionCut, carrotCut], batter)
  let fried = deepFry(coated)
}
schedule kakiage level=1 cooks=1
  0..120 (60) %6 peel by cook1
  120..300 (180) %7 cut by cook1
  300..600 (600) %4 whisk by cook1
  600..780 (660) %9 cut by cook1
  780..900 (900) %11 coat by cook1
  900..1500 (1500) %12 deepFry by cook1

オーブンを温めておく

オーブンを使う動作には温度を書きます。焼き始めに間に合うように、予熱を段取りに入れます。

じゃがいものグラタンpreheat-backward.ozen（抜粋） 
action bake(x: T) -> T<doneness: done> {
  uses HeatSource<oven, heated: 180 degC>
    for 25 min @unattended
}
recipe potatoGratin {
  ingredients { potato: 2 pcs }
  let prepared = prepare(potato)
  let baked = bake(prepared)
}
schedule potatoGratin level=2 cooks=1
  300..2100 (2100) %2 prepare by cook1
  900..2100 (1500) preheat oven#1
    to 180 degC unattended [oven#1]
  2100..3600 (3600) %3 bake unattended [oven#1]
  total 3600

台所に合わせる

フライパンに 250 g しか入らないので、600 g の豚肉を 3 回に分けて焼きます。

豚の生姜焼き（600 g）capacity-compile-time.ozen 
kitchen home {
  places {
    stove: IHStove
  }
  tools {
    pan: FryingPan { capacity: 250 g }
  }
}
recipe porkGinger {
  ingredients { pork: 600 g }
  let batches = ceil(pork / kitchen.pan.capacity)
  repeat batches {
    let fried = fry(pork / batches, 8 min)
  }
}
ozen debug steps --kitchen home capacity-compile-time.ozen

%2 = fry(pork/3, 480 s)
  : Pork<doneness: done,

料理のコードを文章にする

レシピ

人が読める材料と作り方の文章にします。

ozen render --kind recipe --lang ja yasaiItame.ozen 
# yasai itame

## 材料
- 米 150 g
- 玉ねぎ 1個
- にんじん 1本

## 作り方
1. 米を研ぐ、30 分浸す、炊く。
2. 玉ねぎの皮をむく、薄切りにする（3 mm）。
3. にんじんをせん切りにする（3 mm）。
4. 玉ねぎ、にんじんを中火で5 分炒める。
5. 米を盛り付ける。
6. 玉ねぎ、にんじんを盛り付ける。
