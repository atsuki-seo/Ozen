# Ozen reference

The reference for writing Ozen recipes, menus and kitchens.

- [language.md](language.md): the syntax, with examples that are checked against `ozen`
- [std.md](std.md): every action of the standard library `std`, with its parameters, the
  state it needs, and its recipe text
- [diagnostics.md](diagnostics.md): every diagnostic `ozen check` reports
- [ai-guide.md](ai-guide.md): one file for AI agents that write Ozen: the quick syntax, the
  actions, the diagnostics and the work loop
- [agents-template.md](agents-template.md): the `AGENTS.md` that `ozen init` writes into a new
  cookbook

`std.md`, `diagnostics.md` and `ai-guide.md` are generated by `tools/refgen/refgen.py` from
`ozen debug definitions`, `core/src/diag_codes.def`, `phrases/en.ftl` and the part of
`language.md` between the `ai-guide` markers. After changing one of them, run:

```bash
python3 -B tools/refgen/refgen.py
```
